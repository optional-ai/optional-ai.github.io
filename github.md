# Turn off Copilot
To turn off Copilot for your GitHub organisation, adjust settings at https://github.com/settings/copilot/features.

_Note:_ There are several options where AI features are restricted to _Enabled_, such as Copilot Chat in GitHub.com. 

See the following how-to guide to disable Copilot Free: https://docs.github.com/en/copilot/how-tos/manage-your-account/disable-copilot-free

## Opt out of data sharing
On the same page, look for the _Privacy_ section and you will see the "Allow GitHub to use my data for AI model training". The option is Enabled by default.
