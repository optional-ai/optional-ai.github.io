# Browser extensions


- [disable-ai](https://github.com/jruns/disable-ai) works on Firefox, Chrome and Edge. The linked page goes to the source code that includes links to the various extensions pages.

- uBlock Origin can block certain contact. Using a list like [Huge AI Blocklist](https://github.com/laylavish/uBlockOrigin-HUGE-AI-Blocklist) will stop showing up, but the search engine will still execute it.
